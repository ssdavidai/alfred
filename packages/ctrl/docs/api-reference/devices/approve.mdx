---
title: "Approve Pairing"
description: "Approve a pending Hermes DM-pairing code"
api: "POST /api/v1/devices/approve"
---

Approves a pending DM-pairing code, allowing that messaging account to reach
Alfred. Proxies the native `hermes pairing approve <platform> <code>` CLI.

<ParamField header="Authorization" type="string" required>
  Bearer token for API authentication. Use `Bearer YOUR_API_KEY`.
</ParamField>

<ParamField body="platform" type="string" required>
  The messaging platform the code is for — e.g. `telegram`, `slack`,
  `discord`, `whatsapp`, `signal`.
</ParamField>

<ParamField body="code" type="string" required>
  The 8-character pairing code shown to the unknown account when it first
  messaged the gateway (unambiguous alphabet, no `0/O/1/I`; 1-hour TTL).
</ParamField>

<RequestExample>

```bash cURL
curl --request POST \
  --url https://alfred-acme.tailnet.ts.net:3100/api/v1/devices/approve \
  --header 'Authorization: Bearer YOUR_API_KEY' \
  --header 'Content-Type: application/json' \
  --data '{
    "platform": "telegram",
    "code": "XKGH5N7P"
  }'
```

</RequestExample>

<ResponseExample>

```json Response
{
  "message": "Pairing approved"
}
```

</ResponseExample>
