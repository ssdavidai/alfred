---
title: "Clear Pending Pairings"
description: "Drop all pending Hermes DM-pairing codes"
api: "POST /api/v1/devices/clear-pending"
---

Clears all outstanding (unapproved) DM-pairing codes. Approved users are
unaffected. Proxies the native `hermes pairing clear-pending` CLI.

<ParamField header="Authorization" type="string" required>
  Bearer token for API authentication. Use `Bearer YOUR_API_KEY`.
</ParamField>

<RequestExample>

```bash cURL
curl --request POST \
  --url https://alfred-acme.tailnet.ts.net:3100/api/v1/devices/clear-pending \
  --header 'Authorization: Bearer YOUR_API_KEY'
```

</RequestExample>

<ResponseExample>

```json Response
{
  "message": "Pending codes cleared"
}
```

</ResponseExample>
