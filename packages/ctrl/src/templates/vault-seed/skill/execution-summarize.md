# Execution — Summarize Document

How to produce a useful summary of a document or input.

## Methodology
1. Read the full document (use pdf tool for PDFs, read tool for text)
2. Identify the document type (report, email thread, contract, article, etc.)
3. Extract the core message in 1-2 sentences
4. List key facts, decisions, and action items
5. Note any entities (people, orgs, places) mentioned
6. Flag anything time-sensitive

## Output Format
Produce a vault record (type: note) with:
- Clear title summarizing the document
- One-paragraph summary
- Bullet list of key points
- Entities section
- Action items section (if any)

## Quality Standards
- Summaries should be self-contained
- Preserve specific numbers, dates, and names
- Note what type of document this summarizes
