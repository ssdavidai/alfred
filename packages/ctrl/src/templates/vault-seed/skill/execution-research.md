# Execution — Research a Topic or Entity

How to conduct research and produce a briefing.

## Methodology
1. Read the task context — what specifically needs researching and why
2. Check existing vault records — what do we already know?
3. Use web search for external information
4. Cross-reference findings against vault data
5. Assess reliability and confidence of sources
6. Produce a structured briefing

## Output Format
Produce a vault record (type: note) with:
- Title: "{Subject} — Research Briefing"
- Key findings section
- Risk/concern flags (if any)
- Confidence assessment (HIGH/MEDIUM/LOW with reasoning)
- Sources list
- Recommended next steps

## Guardrails
- Be explicit about what you know vs what you inferred
- State confidence levels honestly
- Note data gaps
- Never present inference as fact
- If research dead-ends, say so — do not fabricate thin results
